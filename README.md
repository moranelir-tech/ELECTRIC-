# השוואת חשמל - אתר השוואת ספקים (Next.js)

אתר עברית (RTL) להשוואת ספקי חשמל, עם מחשבון חיסכון, טבלת השוואה דינמית, איסוף לידים ופאנל ניהול.

## הרצה מקומית

```bash
npm install
cp .env.example .env.local   # ולערוך את הערכים
npm run dev                  # http://localhost:3000
```

לייצור: `npm run build && npm start`

## הגדרות (.env.local)

| משתנה | תיאור |
|---|---|
| `SITE_URL` | כתובת האתר, משמשת ל-sitemap, canonical ו-Schema |
| `ADMIN_PASSWORD` | סיסמת פאנל הניהול. בלי סיסמה אי אפשר להיכנס |
| `SESSION_SECRET` | מחרוזת אקראית ארוכה (`openssl rand -hex 32`) |
| `LEADS_WEBHOOK_URL` | אופציונלי: כל ליד חדש נשלח ב-POST (JSON) ל-CRM / Zapier / Make |
| `DATA_DIR` | אופציונלי: תיקיית הנתונים. מומלץ נתיב קבוע בשרת |

## מה יש באתר

- **עמוד הבית** (`/`): מחשבון חיסכון, טבלת השוואה (בנייד הופכת לכרטיסים), טופס לידים, שאלות נפוצות.
- **שני מסלולי המרה לכל ספק**: "מעבר מהיר לספק" (דרך `/go/<slug>`, עם ספירת קליקים והפניה לקישור השותפים) ו"קבלת הצעת מחיר" (חלון השארת פרטים).
- **פאנל ניהול** (`/admin`): עריכת טבלת הספקים (הנחה, שעות, התחייבות, קישור שותפים, סדר, פעיל/מומלץ) בלי לגעת בקוד, צפייה בלידים וייצוא ל-CSV שנפתח באקסל בעברית.
- **SEO**: מטא דינמי, canonical, `sitemap.xml`, `robots.txt`, Schema (FAQPage, ItemList, Article, WebSite), עמוד FAQ ובלוג.
- **אבטחה**: cookie מוגן ל-session, הגבלת קצב ללידים ולכניסה, שדה פיתיון נגד בוטים, אישור הסכמה חובה בטופס, הגנה מפני CSV injection בייצוא.

## איפה העורכים את התוכן

| מה | איפה |
|---|---|
| ספקים, אחוזי הנחה, קישורי שותפים | `/admin` |
| שאלות נפוצות ופוסטים בבלוג | `lib/content.ts` |
| מדיניות פרטיות | `app/privacy/page.tsx` (טיוטה, חובה לעבור עורך דין) |
| עיצוב | `app/globals.css` |

## חשוב לפני עלייה לאוויר

1. **נתוני הספקים הם דוגמה.** יש להחליף אותם בנתונים אמיתיים ומאומתים ב-`/admin`.
2. **אחסון הנתונים הוא קבצי JSON** (`data/providers.json`, `data/leads.json`). זה מתאים לשרת עם דיסק קבוע (VPS, Docker עם volume). ב-Vercel ובשרתים ללא דיסק קבוע הנתונים לא יישמרו, ויש להחליף את `lib/store.ts` במסד נתונים (למשל Postgres/Supabase). כל הגישה לנתונים עוברת דרך הקובץ הזה בלבד.
3. **טקסטים משפטיים**: מדיניות הפרטיות והגילוי הנאות הם טיוטות. בעת מכירת לידים לצד שלישי נדרשת הסכמה מפורשת (קיימת בטופס) ומדיניות פרטיות מעודכנת.
4. **HTTPS ומהירות**: מומלץ Cloudflare מול השרת, והפעלת HTTPS. האתר קל במיוחד (כ-105KB JS בעמוד הבית).
5. החישוב מניח שההנחה חלה על כל החשבון. אם יש ספקים עם תנאים מורכבים יותר (הנחה רק בשעות מסוימות), אפשר להרחיב את `lib/calc.ts`.

## העלאה לאוויר (Railway או Render)

הפרויקט כולל `Dockerfile` ו-`render.yaml`. הנתונים (ספקים ולידים) נשמרים בתיקייה `/data`, ולכן חובה לחבר דיסק קבוע.

### Render
1. להעלות את התיקייה לריפו חדש ב-GitHub (פרטי).
2. ב-Render: New > Blueprint, לבחור את הריפו. הקובץ `render.yaml` מגדיר שירות עם דיסק של 1GB.
3. למלא את `ADMIN_PASSWORD` ואת `SITE_URL` (הכתובת הזמנית שRender נתן, בפורמט https://...). `SESSION_SECRET` נוצר אוטומטית.

### Railway
1. להעלות לריפו ב-GitHub, ב-Railway: New Project > Deploy from GitHub.
2. Settings > Volumes: להוסיף Volume עם Mount path `/data`.
3. Variables: `ADMIN_PASSWORD`, `SESSION_SECRET`, `SITE_URL`, `DATA_DIR=/data`.
4. Settings > Networking: Generate Domain.

### אחרי העלייה
- להיכנס ל-`/admin`, להחליף את נתוני הדוגמה בספקים אמיתיים.
- לחבר דומיין: בספק האחסון Custom Domain, ולעדכן את `SITE_URL` לכתובת הסופית (הערך נקרא בזמן build, לכן צריך deploy מחדש).
- לשלוח את `https://<הדומיין>/sitemap.xml` ב-Google Search Console.
